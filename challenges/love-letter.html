The secret message

A student scrambled a secret word using this Python code:

message = "????"
secret = []
for letter in message:
    secret.append(ord(letter) * 3)
print(secret)

The program printed:

[297, 333, 300, 303, 156, 306, 351, 330]

Hint: ord turns a letter into its ASCII number. Can you work backwards to find the message?
