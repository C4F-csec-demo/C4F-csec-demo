How to use this website (teachers)

This page explains everything teachers can do on the site. If you only read one part, read Quick start.

1. Quick start

  1. Go to the Teacher page and log in (or create an account, see section 2).
  2. Under My classes, type a class name (like "PLC Year 7 Tuesday") and click Create class.
  3. You'll see the class's join code (6 letters and numbers on a yellow background). Write it on the board.
  4. Students go to the student page, click Register, and type the join code, their first and last name, and a password.
  5. In the Lessons box, pick a lesson and a day, then click Assign. Students can now open that lesson's challenge.
  6. Want a competition? Click Set up a Live CTF in the pink box. See section 8.

Anywhere you see a little ?, hover over it (or tap it) for a quick explanation.

2. Your teacher account

Making an account

  1. Go to the Teacher page and click Create account.
  2. Type your email, a password (at least 8 characters, and please don't reuse one from somewhere else) and your name.
  3. If an admin gave you an invite code, type it in too. Your account is approved straight away.
  4. No invite code? You'll see "Waiting for approval". Ask Ben or Grig to approve you, then click Refresh. If you get an invite code later, you can type it in on that same screen.

Forgot your password

Ask an admin (Ben or Grig). They can set a new password for you from the Admin page.

Signing out

Click Sign out in the top right. Always sign out on shared school computers.

A teacher account and a student account can't be the same login. If you want to see what students see, use a separate student account in a different browser or an incognito/private window.

3. Classes and join codes

  • Make a class: on My classes, type a name and click Create class.
  • Open a class: click its tile. You'll see its join code, the Live CTF box, its lessons and its students.
  • Join code: every class has its own code. Students need it to register and to log in, so it's fine to leave it on the board.
  • Rename a class: open it and click Rename class.
  • Shared classes: a class can have more than one teacher (for example a substitute). Everyone listed next to "Teachers" can see and manage the class. Only admins can share a class or hand it over to someone else (see section 10).
  • Deleting a class: only admins can do this, because it deletes all the students' logins too.

4. Students

How students register and log in

Students don't need an email. They register on the student page with the class join code, their first and last name and a password (6+ characters). After that they log in with the same three things. Names aren't case sensitive, so "amy lee" works for "Amy Lee".

Two students in the same class can't have exactly the same first and last name. If that happens, ask one of them to add a middle initial to their last name (for example "Lee J").

Things you can do in the Students table

  • Rename: fix a typo in a student's name. Type their first name, a space, then their last name. Tell them, because they log in with their name.
  • New password: for when a student forgets their password. Type a temporary password and tell the student. Students can't change or reset passwords themselves.
  • Remove: deletes the student and their login completely. This can't be undone.
  • Challenges solved: how many challenges they've solved during normal lessons. Hover over the number to see which ones. (Live CTF answers aren't counted here.)

5. Giving lessons to a class

  1. Open the class.
  2. In the Lessons box, pick a lesson from the list and a day.
  3. Click Assign.

Students see a lesson from its day onwards. So you can assign next week's lesson today, and students won't see it until next week. The status shows either Students can see it or Unlocks Thu 22 Oct 2026.

Click Unassign to take a lesson away from the class.

What students see

On their page, students see each lesson with an Open challenge button (and an Open resource button if the lesson has a resource link). A challenge page has the challenge and an answer box. When they get it right it says "Correct!" and the lesson gets a Solved badge.

You can open any challenge page and check answers yourself while logged in as a teacher. Your answers aren't recorded anywhere.

6. The curriculum and adding lessons

The Curriculum tab on the teacher page lists every lesson, grouped by level, like the Code4Fun curriculum spreadsheets. For each lesson you can see:

  • Resource: a link for the lesson (for example a demo page).
  • Lesson plan: a link to the lesson plan document.
  • Challenge: the challenge page students open.
  • Flag: the answer to the challenge. It's blurred so it isn't shown by accident on a projector. Click it to show it.

Adding a lesson

  1. Fill in the Add a lesson form at the bottom: level, lesson number and title. Links are optional.
  2. Challenge id is the file name of the challenge page in the website's challenges folder, without ".html". For example caesar for challenges/caesar.html.
  3. Flag is the answer. You only need it if the challenge is new. If the challenge already exists, leave it empty.
  4. Click Add lesson.

New lessons show Waiting for approval until an admin approves them. Until then, only you and the admins can see them, and they can't be assigned to classes. (Lessons added by admins are approved straight away.)

Only admins can delete lessons.

Adding a lesson doesn't make a new challenge page. The page itself (the HTML file) has to be added to the website by Ben.

7. Lessons vs Live CTF

The site has two separate ways to use challenges:

Lessons Live CTF
What it's for Learning a concept and practising at your own pace A timed competition with a live leaderboard
Looks like Light background, teal colours Dark background, pink "LIVE CTF" badge
Students open it from Their lesson list The pink "Join the Live CTF" button on their page
Timing and points None, just "Correct!" Each challenge is timed, faster = more points
Counts towards "Challenges solved" in the Students table Only that Live CTF's leaderboard

A Live CTF can use any challenge, even ones the class hasn't been assigned. Keep in mind that if students already solved a challenge in a lesson, they'll know the answer.

8. Running a Live CTF

Step 1: Set it up

Open the class and click Set up a Live CTF in the pink box. Then:

  1. Name: anything you like. It's shown on the big screen.
  2. Challenges: click them in the order you want them. Each one gets a number. Click one again to take it out.
  3. Pacing:
    • Self-paced: each student (or team) moves to the next challenge as soon as they solve one. They can also skip a challenge for 0 points if they're stuck.
    • Teacher-paced (like Kahoot): everyone works on the same challenge at the same time. When you're ready, click Next challenge on the big screen. There's no skipping.
  4. Time limit: optional. Leave it empty for no limit. When time runs out, nobody can answer and the results are shown.
  5. Teams: tick Play in teams if you want teams. Then choose:
    • Number of teams (2 to 12).
    • Max students per team (optional). This only stops students picking a full team. You can still move anyone anywhere.
    • How are teams made: Students pick a team (they click a team to join it), or Random (you click Shuffle teams in the lobby).
    • Team names and colours: Automatic (Team 1, Team 2... each with a different colour) or Students choose (each team picks its own name and colour in the lobby).
    Without teams, everyone plays on their own and shows on the leaderboard as their first name and last initial (like "Amy L.").
  6. Click Open the lobby. This takes you to the big screen. Put it on the projector.

A class can only have one Live CTF open at a time.

Step 2: The lobby (students join)

Students log in as normal. Within a few seconds a pink Join the Live CTF button appears on their page. When they click it, they show up on your screen.

In the lobby you can:

  • Move a player to another team with the little menu next to their name.
  • Remove a player from the game with the × next to their name. (They can rejoin from their page.)
  • Shuffle teams: puts everyone into random teams, spread out evenly.
  • + Add team, or delete a team with the × in its coloured bar.
  • Rename a team or change its colour with the ✎ (pencil) button. Pick a colour another team has and the two teams swap colours, so no two teams ever share one. Use this if students choose an inappropriate name.
  • Cancel CTF if you change your mind.

When students choose team names, they can change them until you press START. After that, only you can change them.

Anyone who isn't in a team when you press START is put into the smallest team.

Step 3: START

Click START. Students' screens change to the first challenge, and the timer starts.

The big screen shows:

  • The timer (counting up, or counting down if you set a time limit).
  • A box for each challenge showing who solved it fastest (with their team colour) and how long it took. If someone beats that time later, the box updates.
  • The leaderboard, which updates every couple of seconds. Rows slide up and down as places change. In self-paced mode it also shows which challenge each team is on.

Teacher-paced: the current challenge's box is highlighted with its own timer. Click Next challenge to move everyone on. On the last challenge the button says Finish.

Students who join after START can still play. Without teams, their clock starts when they join. With teams, they go into the smallest team.

Step 4: The end

The CTF ends when you click End CTF (or Finish), or when the time limit runs out. The big screen shows a podium and the final leaderboard. Students see their place and the top 5.

Past Live CTFs are listed in the pink box on the class page. Click Results to show the results again, or Delete to remove one.

What students see

Students see a dark screen with their score, place, the overall timer, and a timer for the challenge they're on. The challenge appears in the middle with an answer box above it. When they (or a teammate) solve a challenge, a pop-up says "Good work, you completed the challenge!" with their points, their place, and how many points behind the next team they are.

9. How Live CTF scoring works

Every challenge is timed on its own. The faster a student or team solves a challenge, the more points they get for it:

Time to solve Points
Straight away1000
1 minute833
2 minutes750
5 minutes643
10 minutes583
Skipped0

Solving a challenge is always worth at least 500, so slower students still get plenty of points.

Because each challenge has its own clock, a slow start doesn't ruin the whole game. Being fast on the next challenge lets a team catch up.

  • Self-paced: a challenge's clock starts when the team finished (or skipped) the one before it. The first one starts at START.
  • Teacher-paced: the clock starts when you show that challenge.
  • Teams: anyone in the team can type the answer. The whole team moves on together and shares the points.
  • Ties: if two teams have the same points, the one that got there first is ahead.
  • Answers aren't case sensitive, and spaces at the start and end are ignored.

10. Admin page (Ben and Grig)

Admins see an Admin link at the top of the teacher page. Admins can also see every class on the teacher page by ticking Show every class (admin).

Teachers tab

  • Waiting for approval: people who made a teacher account without an invite code. Click Approve, or Reject and delete if you don't know them.
  • Add a teacher: type their name and click Make invite code. Give them the code. They go to the Teacher page, click Create account, and type the code. Each code works once. Cancel unused codes you don't need.
  • Make admin / Remove admin: admins can use this page.
  • New password: set a new password for a teacher who forgot theirs (8+ characters, not reused from anywhere else).
  • Block: stops a teacher using the site until you approve them again. Their classes stay.
  • Delete: deletes their login. Their classes stay, so give them to another teacher.
  • You can't change your own account here, so you can't lock yourself out by accident.

Lessons tab

  • Approve lessons that teachers added. You can check the links and the flag first.
  • Delete any lesson. This also unassigns it from every class. (The challenge page and its answer stay, so other lessons can still use it.)

Classes tab

  • Share a class (for example with a substitute): pick a teacher next to the class and click Add. Both teachers can now manage it.
  • Hand a class over (for example a teacher leaves): add the new teacher, then click × next to the old teacher.
  • Open takes you to the class page, even if you don't teach it.
  • Delete deletes the class, all its students' logins and its Live CTF results. You have to type DELETE to confirm.

11. Common problems

A student says "Class code or name not found"
Check the join code, and check their name is spelt the same way as when they registered (look at the Students table). Maybe they haven't registered yet.
A student says "Someone with that name is already in this class"
They already registered. They should click Log in instead. If they forgot their password, give them a new one.
A student can't see a lesson
Check the day you assigned it. Lessons only show from that day (Sydney time).
Students can't see the Join the Live CTF button
Make sure they're logged in to the right class, and that you opened the lobby for that class. The button appears within about 5 seconds. Refreshing the page also works.
A student is in the wrong team
Use the menu next to their name on the big screen to move them.
I closed the big screen by accident
No problem, the game keeps going. Open the class and click Open the big screen.
The answer checker says "Log in first"
Challenge pages only check answers for people who are logged in (teachers or students).
